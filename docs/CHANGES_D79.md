# Crafting and contact repair

I kept the tested D78 source frozen and applied the reviewed repair in a separate
checkout. The good forge placement and improved unholstering are the baseline.

## Crafting

A progressing mortar grind could cross a five-second watchdog and lose ownership
just before its native Use event. The current exact child may now continue within
the existing request lifetime. A cancelled tip over a recipient withdraws only
an unentered request; it cannot replay a completed contents change.

The smith collision reader now distinguishes the workpiece attached to the tongs
from one already left inside the forge. The latter must not pull the hand toward
an old held-item proxy. Hammer scoring and forge placement are unchanged.

F5 now records instant semantic completion separately from ordinary authored
WORK milestones. A successful contents readback still does not prove a sound,
particle effect or rendered prop was seen. Those fields explicitly stay unknown.

## Hands and pickup

Balanced contact adds two stable fingertip samples to the palm query, without
finger curling or extra query budget. Layout changes retire incompatible contact
history. Contact-only return uses high-resolution sample time; pulling away from
a surface remains immediate. No smoothing was added to ordinary tracking.

Instant pickup now owns the tracked hand throughout its active native request,
without borrowing permission from an F5 capture. Native selection, inventory and
eligibility stay in charge. Dialogue finger curl reads visual Trigger separately
from filtered gameplay Trigger, so moving the index finger does not attack or use.

## Related reviewed transitions

The update includes the reviewed crossbow mechanism/socket joins, exact-target
Quick Talk receipt, F9 corpse press reservation, and paired map-pose snapshot.
These are code-tested transitions, not new claims of complete headset behavior.
Dog petting and ordinary riding hands default ON; saved OFF remains respected.

## Dialogue bars

The ratio-strip hide now runs at the earliest worker point with the current
native dialogue and final Theater decision. It retries briefly on entry and HUD
recreation, and restores only the HUD generation it actually changed. Failed
restoration stays pending rather than giving up after three attempts.

This does not establish a hook before the first rendered dialogue frame. Native
Flash animation can still reset the child after the bounded entry window; that
needs an exact movie update/display boundary. Cutscenes and native dialogue
cameras never qualify for this mask owner.

## Bow preservation

The proposed bow-learning change was held out. It correctly rejected one
self-preview case, but another valid native pose could remain pending when a
single joint matched the preview. Accepted native controls otherwise produced
the same learned axes. That is insufficient reason to change shooting again.
The existing bow calibration, grip/shot equations and draw visibility are kept.
No guessed left/right aim compensation was added. The reported D78 shot offset
is still open.

## Limits

No new headset run is claimed. Complete free-hand smoothness, all crafting audio
and particles, corpse dragging in every save, throwing knives and every crossbow
reload are not established by this revision. Camera matrices, stereo scheduling,
combat outcomes and user calibration are unchanged. Optional gore remains a
separate package.
