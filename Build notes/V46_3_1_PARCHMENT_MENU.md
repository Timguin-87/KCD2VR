# V46.3.1 Parchment Menu Revision

This revision changes **only the visual styling** of the V46.3 in-backbuffer menu.

- warm aged-parchment palette
- dark iron-gall/brown text
- muted rubric red accents
- double manuscript border and simple ornaments
- Georgia title/normal text with Segoe UI retained for compact diagnostics
- no extracted KCD2 textures, fonts, or copyrighted UI assets

The D3D12 overlay renderer, command-list ordering, game-device reuse, input subclass, F7/F8 behavior, OpenXR bridge, CVar profile, stereo probes, and matrix logic are unchanged from V46.3.
